User Groups
← Back to Settings
Each group has a password and a set of capability flags. Players enter one of these passwords at the connect prompt; their granted capabilities are determined by which group's password they used. Saving will stop the server, rewrite the config, and leave the server stopped — restart it from the Dashboard when you're done editing.

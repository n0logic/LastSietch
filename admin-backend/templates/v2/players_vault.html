Base Vault

Capture a placed base and inspect its snapshot history. Each archive preserves saved structures, items and ownership without changing the game world.

Looking for packed bases? Open BRT backups. Vault snapshots do not use a BRT slot.

Using Base Vault
  1. Find the placed base by its owner, totem and map instance, then open its vault.
  2. Choose Take snapshot. Capture reads saved database state while the game keeps running. Recent unsaved changes may be absent.
  3. Wait for capture and checksum verification, then inspect the saved timestamp, table counts and archive checksums in history.
  4. Choose Stage for restore on the intended snapshot. Review its original owner and location, compatibility, ID collisions, dependencies and map lifecycle checks. Staging only records a plan.

A database round-trip validates the archived graph in an isolated database. It does not prove an in-game restore. If a request times out, Check status reads the existing operation without submitting another capture. An uncertain outcome blocks further capture for operator review.

Takedowns

All three write, all three are reversible, and none of them deletes a row. Every press is audited with the reason you type and with the state it replaced, which is what an undo needs later.

Signal Board: guild card

any admin

Sets recruiting off or back on for one guild. The blurb, the contact note and the filters are untouched.

Signal Board: seeker card

any admin

Expires or restores one looking for guild card. Expiring stamps the same expiry a card reaches on its own; nothing is deleted. Two players under one name is refused, not guessed at.

Player directory listing

any admin

Takes one player out of the public directory, or puts them back. It writes the listed flag and nothing else, so the blurb survives and restoring brings the profile back exactly as it was.
